# 悦安月子中心 · 产妇护理计划与家属探访平台

月子中心业务一体化平台：覆盖**入住登记 → 护理计划执行 → 多角色协同异常处置 → 宝宝黄疸分级处置与转诊闭环 → 家属探访/授权查看 → 出所结算 → 出所后随访与复购转介绍**全流程。所有角色（护理师、护士长、儿科医生、营养师、产康师、月嫂、前台、财务、家属、中心管理者）围绕**同一间房**协同工作。

## 技术栈

- **Next.js 15（App Router, TypeScript）**：服务端渲染页面 + API 路由（前后端一体）
- **数据库**：Node 22 内置 `node:sqlite`（文件库 `data/mcare.db`，首次启动自动建表+播种演示数据）。SQL 均为标准语法，表结构可直接迁移到 MySQL（将 `datetime('now','localtime')` 默认值替换为 `CURRENT_TIMESTAMP` 即可）
- **认证**：HMAC 签名 httpOnly Cookie 会话，SHA-256 加盐口令哈希
- 无外部服务依赖，克隆后安装依赖即可运行

## 本地启动

### 方式一：Docker 一键启动（推荐）

```bash
docker compose up --build -d   # 构建并后台启动
# 打开 http://localhost:3000 （首次启动自动建表+播种演示数据，数据持久化在 mcare-data 卷）
docker compose logs -f         # 查看日志
docker compose down            # 停止
```

### 方式二：本地 Node 启动

```bash
npm install        # 安装依赖（Node.js ≥ 22.5，需内置 node:sqlite）
npm run dev        # 开发模式 http://localhost:3000
# 或生产模式：
npm run build && npm start
```

首次启动自动创建 `data/` 并写入演示数据（含在住订单 2 个、已出所订单 1 个、各角色账号）。删除 `data/` 目录即可重置为初始演示数据。

## 功能地图（需求 → 实现）

- **入住档案**：分娩方式、产后天数、过敏史、哺乳方式、宝宝体重、黄疸观察、房型套餐、餐食禁忌、家属探访权限、医生建议（前台入住登记表单，自动建护理计划/赠品/费用/家属账号）
- **护理安排**：查房、伤口观察、乳房护理、产康课程、月子餐、宝宝洗澡抚触、夜间照护（护理计划+每日任务，护士长可增改）
- **家属端**：经授权的护理摘要（仅可见标记记录）、探访预约（含临时探访）、费用明细、意见反馈、随访安排、与中心留言
- **异常协同**（围绕同一间房，工单+时间线+角色路由）：黄疸升高→儿科；乳腺堵塞/记录质疑/退所争议→护士长；临时探访→前台；月嫂请假→护士长改派；餐食忌口→营养师（配餐自动核对）；产康延期→产康师；套餐升级/提前退所→费用折算+工单
- **宝宝黄疸分级处置与转诊闭环**（`jaundice_cases/measurements/events/todos` 四表）：
  - 护理师上报测量时间、测量方式（TCB 经皮/TSB 血清）、趋势、喂养与排泄，平台自动快照既往观察计划与医生既往建议，按阈值分级为**加强复测 / 医生当班评估 / 紧急转诊**（TCB：≥15 紧急转诊、12–15 医生评估、≥10 且上升加强复测；TSB 阈值 18/15/12）
  - **医生确认前**不生成家属可见口径，护理师不能自行承诺转诊或调整治疗；家属端只展示经医生确认的处理建议；复测继续升高自动退回医生确认
  - 医生建议转诊后必须**取得家属确认**，再协调车辆、陪同人员、目标医院与中心护理交接材料；**车辆或陪同人员拒绝导致延迟时自动升级护士长并保留风险说明**（家属拒绝转诊同样升级留痕、继续留观）
  - 宝宝返中心后登记**外院回执**：与原中心计划冲突（如外院要求停母乳而中心为母乳喂养）时挂起常规护理，**必须医生复核**；复核通过后依回执与新建议**重建观察计划、取消过期复测提醒、同步护理师排班**，随后恢复常规护理
  - 护理主管（护士长）可在房间视图与工作台查看**全程时间线、交接材料、未完成事项**，全部办结后才能关闭闭环，避免复测、转诊与返中心记录脱节
- **出所后**：护理计划与异常记录留存、费用结算单、回访/母婴随访计划、复购与转介绍线索
- **其他**：套餐赠品发放、产康师排班、宝宝托管日志、探访消毒登记、房间升级（自动换房+补差价）、医生巡诊记录
- **管理者**：按房间聚合护理动作、家属沟通、费用变化、异常处置；高敏感客诉区（记录质疑/退所争议/忌口异常/低分反馈）；口碑均分
- **反馈联动**：家属反馈可被护士长标记"影响护理师排班"，低分反馈进入管理看板；护理记录进入出所后母婴随访；退所争议自动同步护士长
