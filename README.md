# 悦安月子中心 · 产妇护理计划与家属探访平台

月子中心业务一体化平台：覆盖**入住登记 → 护理计划执行 → 多角色协同异常处置 → 家属探访/授权查看 → 出所结算 → 出所后随访与复购转介绍**全流程。所有角色（护理师、护士长、儿科医生、营养师、产康师、月嫂、前台、财务、家属、中心管理者）围绕**同一间房**协同工作。

## 技术栈

- **Next.js 15（App Router, TypeScript）**：服务端渲染页面 + API 路由（前后端一体）
- **数据库**：Node 22 内置 `node:sqlite`（文件库 `data/mcare.db`，首次启动自动建表+播种演示数据）。SQL 均为标准语法，表结构可直接迁移到 MySQL（将 `datetime('now','localtime')` 默认值替换为 `CURRENT_TIMESTAMP` 即可）
- **认证**：HMAC 签名 httpOnly Cookie 会话，SHA-256 加盐口令哈希
- 无外部服务依赖，克隆后安装依赖即可运行

## 本地启动

```bash
npm install        # 安装依赖（Node.js ≥ 22.5，需启用内置 node:sqlite）
npm run dev        # 开发模式 http://localhost:3000
# 或生产模式：
npm run build && npm start
```

首次启动自动创建 `data/` 并写入演示数据（含在住订单 2 个、已出所订单 1 个、各角色账号）。删除 `data/` 目录即可重置为初始演示数据。

### Docker 一键启动

```bash
docker compose up --build        # 构建并启动，访问 http://localhost:3000
# 或：
docker build -t mooncare . && docker run -p 3000:3000 -v mooncare-data:/app/data mooncare
```

SQLite 数据持久化在命名卷 `mooncare-data`（容器内 `/app/data`）；生产部署请通过环境变量 `MCARE_SECRET` 覆盖会话签名密钥（见 `.env.example`）。

> 说明：本沙箱环境未安装 Docker，Dockerfile / docker-compose.yml 已按 Node 22 多阶段构建写好但**未在本机实际构建运行**；已实际执行验证的是下方的 `npm run build` + `npm run smoke`。

## 功能地图（需求 → 实现）

- **入住档案**：分娩方式、产后天数、过敏史、哺乳方式、宝宝体重、黄疸观察、房型套餐、餐食禁忌、家属探访权限、医生建议（前台入住登记表单，自动建护理计划/赠品/费用/家属账号）
- **护理安排**：查房、伤口观察、乳房护理、产康课程、月子餐、宝宝洗澡抚触、夜间照护（护理计划+每日任务，护士长可增改）
- **家属端**：经授权的护理摘要（仅可见标记记录）、探访预约（含临时探访）、费用明细、意见反馈、随访安排、与中心留言
- **异常协同**（围绕同一间房，工单+时间线+角色路由）：**宝宝黄疸升高分级处置与转诊闭环（见下）**；乳腺堵塞/记录质疑/退所争议→护士长；临时探访→前台；月嫂请假→护士长改派；餐食忌口→营养师（配餐自动核对）；产康延期→产康师；套餐升级/提前退所→费用折算+工单
- **宝宝黄疸分级处置与转诊闭环**：
  - 护理师测量时记录**测量时间、测量方式（TCB/TSB）、趋势、喂养与排泄情况、既往观察计划与医生建议**（既往信息自动带入可覆盖），平台按阈值自动分级：**12.0–14.9 加强复测 / 15.0–17.9 医生当班评估 / ≥18.0 紧急转诊**
  - **家属端只展示经医生确认的处理建议**；医生确认前护理师不能代替医生确认、不得向家属承诺转诊或调整治疗说明（服务端强制门控）
  - 医生可确认「加强复测 / 医生当班评估 / 建议转诊」；非转诊自动下发复测提醒到护理师排班
  - 医生建议转诊时，必须先**取得家属确认**，护士长才能协调**车辆、陪同人员、目标医院、中心护理交接**四要素
  - **车辆无法安排或家属拒绝导致转诊延迟 → 自动升级护士长并保留风险说明**（异常工单同步置为紧急）；护士长沟通后家属可重新确认
  - 登记转诊出发/到达；**宝宝返中心后登记外院回执与外院建议**，系统判断是否与原中心计划冲突
  - **外院建议与原中心计划冲突时必须由医生逐项复核**，复核后系统**重建观察计划、取消过期黄疸提醒、同步护理师排班**，随后才恢复常规护理
  - 护理主管在房间360视图可看**全程时间线、交接材料与未完成事项**，复测/转诊/返中心记录串联不脱节
- **出所后**：护理计划与异常记录留存、费用结算单、回访/母婴随访计划、复购与转介绍线索
- **其他**：套餐赠品发放、产康师排班、宝宝托管日志、探访消毒登记、房间升级（自动换房+补差价）、医生巡诊记录
- **管理者**：按房间聚合护理动作、家属沟通、费用变化、异常处置；高敏感客诉区（记录质疑/退所争议/忌口异常/低分反馈）；口碑均分
- **反馈联动**：家属反馈可被护士长标记"影响护理师排班"，低分反馈进入管理看板；护理记录进入出所后母婴随访；退所争议自动同步护士长
